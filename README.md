<h1 align="center">React Native · Mobile Product Engineer</h1>

---

Android에서 출발해 React Native 생태계로 범위를 넓혀온 모바일·프론트엔드 엔지니어입니다. 주로 플랫폼서비스에서 복잡해진 레거시 코드를 안정적인 타입과 명확한 도메인 기준으로 정리하고, 배포 자동화와 지표 계측을 정착시켜 팀의 개발 생산성을 끌어올리는 일을 해왔습니다.

1인 개발의 빠른 초기 런칭부터 서비스 확장기의 React Native 리드까지 경험하며, 화면 구현에 머무르지 않고 한정된 리소스 안에서 가장 실용적인 선택으로 **사용자 경험을 개선하고 제품·비즈니스의 성장에 기여**하는 것을 중요하게 생각합니다. 지금은 슬로우 저널 앱 **오롯**을 기획부터 운영까지 직접 만들고 있습니다.

#### Moment Select

> 수백 장의 사진을 넘기며 남길 사진만 고르는 웹앱입니다. 스튜디오에서 웨딩 원본 1,500장을 받고 30장을 골라야 하는 날을 위해 만들었습니다. 잘 나온 사진부터 보여 주고, 거의 같은 연사는 묶어 주며, 두 사람이 따로 고른 뒤 합칠 수 있습니다.
> 사진은 브라우저 안에서만 분석하고 어디에도 올리지 않습니다. 고르는 동안 내 선택을 배워 남은 사진의 순서를 다시 맞춥니다.

#### Groove Skater

> 돌아가는 레코드 위의 작은 스케이터가 바늘이 되는 웹페이지입니다. 스케이터가 달리는 자리가 곧 들리는 소리라서, 판과 같은 방향으로 달리면 곡이 거꾸로 재생되고 점프하면 바늘이 들립니다. PLAY를 누르면 모터가 꺼지고, 박자에 맞춰 판을 밀어 곡을 살려야 합니다.
> Bénédict Aubry의 모션 작품 "Roller"(Motiontober 2026)를 원작자의 허락을 받아 인터랙티브로 옮겼습니다.
